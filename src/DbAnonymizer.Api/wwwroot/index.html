DbAnonymizer

Санитизация копий баз данных: персональные и чувствительные данные заменяются синтетическими значениями, чтобы дамп можно было безопасно передать командам разработки.

Новая задача

Только custom-формат (один файл). Для directory-формата (`-Fd`, параллельный дамп больших БД) — путь на сервере через API (см. README).

Роль источника должна иметь право только на чтение (см. «Ограничения» в README).

Экраны

  • Задачи обезличивания — список задач: ревью плана, заморозка, отчёты о результате.
