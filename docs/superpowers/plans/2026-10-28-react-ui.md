# React UI implementation plan

**Goal:** Replace the four static pages with React and build the frontend automatically with the API in Visual Studio and CLI.

**Architecture:** React + Vite in `src/DbAnonymizer.Api/ClientApp`, compiled into generated `wwwroot`. ASP.NET serves the existing page URLs explicitly; API URLs remain unchanged. MSBuild restores npm dependencies when the lockfile changes and builds before static assets are collected. Docker uses a separate Node build stage.

**Scope:** Preserve the existing Russian UI, upload/live-source creation, jobs, plan strategies/freeze, and reports. Keep edits across table filters, including separate JSON paths. Do not change the processing pipeline.
